Rive Code Generator
Usage: ../build/out/lib/debug/rive_code_generator [OPTIONS]

Options:
  -h,--help                   Print this help message and exit
  -i,--input TEXT:(FILE) OR (DIR) REQUIRED
                              Path to Rive file or directory containing Rive files
  -o,--output TEXT REQUIRED   Output file path
  -t,--template TEXT          Custom template file path
  -l,--language ENUM:value in {dart->0,js->1} OR {0,1}
                              Programming language for code generation
  -e,--engine ENUM:value in {inja->1,mustache->0} OR {1,0}
                              Template engine to use (mustache or inja)
  --ignore-private            Skip artboards, animations, state machines, and properties starting with 'internal', 'private', or '_'
